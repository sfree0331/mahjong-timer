# 麻雀対局タイマー 🀄

**▶ 公開URL: https://sfree0331.github.io/mahjong-timer/**
（スマホでこのURLを開いて「ホーム画面に追加」でアプリとしてインストールできます）

競技麻雀・健康麻雀・セット麻雀向けの**持ち時間制対局タイマー** PWA。
チェスクロックのように 4 人が独立した持ち時間を持ち、手番の間だけ時間が減ります。
対局中に**片手・最小タップ**で操作できることを最優先に設計しています。

- 📱 スマホ最優先・縦横対応・iPhone / Android 対応
- 📴 完全オフライン動作（PWA・ホーム画面インストール可）
- 🔧 依存ライブラリゼロ・ビルド不要（Vanilla JS / ES Modules）
- 🀄 **4人打ち / 3人打ち（サンマ）対応**（設定で切替）

## 使い方

### 起動

静的ファイルを HTTP で配信するだけで動きます（ES Modules のため `file://` 直開きは不可）。

```bash
npx http-server -p 8080 -c-1 .
```

ブラウザで `http://localhost:8080` を開く。GitHub Pages / Netlify 等にそのまま置いてもOK。

### 使い方ガイド

**初回起動時に使い方ガイドが自動で表示されます**（6ステップ）。
右上の「？」ボタンからいつでも見返せます。

### 基本操作

操作はひとつだけ — **タップした人にタイマーが飛んで、その人の時間が進みます。**
開始前でも一時停止中でも、誰かのタイルをタップすればその人から計測が始まります。

高速対局向けに、局表示（東1局・南2局など）は持ちません。
ロン/ツモ/流局を押すと**その場で記録が保存され、即座に次の局を始められます**
（確認画面なし。間違えたら Undo で記録ごと戻せます）。

| 操作 | 方法 |
|---|---|
| 開始 / 手番移動 / 鳴き / 再開 | **次に考える人のタイルをタップ**（それだけ） |
| 順送りしたいとき | 卓（中央の緑）をタップ → 次の人へ |
| ロン / ツモ / 流局 | ワンタップで即記録 → そのまま次局へ。トーストと中央の「記録 n局」で保存を確認できる |
| 一時停止 | 右上「⏸ 停止」（再開は誰かのタイルをタップ） |
| Undo | 「↩ Undo」で手番・時間・直前の記録を 1 手戻す（20 件まで） |

### タイマー表示・延長ルール

- 手番のプレイヤーは**カラーのグロー**で光ります
- 残り **30 秒で黄色**、**10 秒で赤**（音+バイブ）、**0 秒で点滅**
- 持ち時間は局をまたいで持ち越し（持ち時間制）
- **持ち時間を使い切ると自動で延長時間（デフォルト 3 分）が 1 回付与**されます
  （例: 10 分切れ → 3:00 から再スタート、タイルに「延長」表示）。
  延長も使い切ると点滅して自動停止します。延長時間は設定で なし / 1 / 3 / 5 分 に変更可能

### 3人打ち（サンマ）

設定 →「人数」で **4人打ち ⇔ 3人打ち** を切替できます（タイマーは初期化・記録は残ります）。
3人打ちでは北家が消え、手番は東→南→西で回ります。

### 設定（右上「設定」）

人数（4人/3人）・**名前**（色は固定）・持ち時間（5/10/15/20/30/60 分 + 自由入力）・延長時間・
効果音・バイブ・ライト/ダークテーマ・文字サイズ。状態は **LocalStorage に自動保存**され、
アプリを閉じても続きから再開できます。
「**新しい対局を開始**」でタイマーだけ初期化できます — **保存済みの記録は消えません**。

### 保存ログ（右上「ログ」）

局ごとに通し番号・開始/終了時刻・各人の思考時間・平均思考時間を自動記録。
保存件数は画面中央にも常時表示されます。
**CSV / JSON でエクスポート**でき（CSV は Excel 対応の BOM 付き UTF-8）、
「記録を全削除」はログ画面から明示的に行います。

## PWA インストール

- **iPhone (Safari)**: 共有 →「ホーム画面に追加」
- **Android (Chrome)**: メニュー →「アプリをインストール」

インストール後は完全オフラインで動作します。

## 開発

```bash
npm test   # コアロジックのユニットテスト（node:test・依存なし）
```

> **デプロイ時の注意**: Service Worker はキャッシュ優先で配信するため、ファイルを更新したら
> [sw.js](sw.js) 先頭の `CACHE` バージョン（例: `mahjong-timer-v2.1.1`）を上げてください。
> 旧キャッシュは activate 時に自動削除されます。

### 公開（GitHub Pages）の更新手順

公開サイトは `gh-pages` ブランチから配信されています。更新は次の2コマンド:

```bash
git push origin main
git push origin main:gh-pages
```

- 設計書: [docs/DESIGN.md](docs/DESIGN.md)（アーキテクチャ・状態機械・データ構造・イベントフロー・拡張方針）
- コアロジック（`js/core/`）は DOM 非依存の純粋モジュールで、View（`js/views/`）と
  ブラウザ API ラッパ（`js/services/`）から分離された MVVM 構成です

## 動作要件

iOS 16.4+ / Android Chrome 111+ 相当（`color-mix()`, `100dvh` を使用）。
