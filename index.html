使い方ガイド

  1. 👆
    タップした人の時間が動く
    最初に考える人（親）のタイルをタップすると計測開始。 打牌したら次の人をタップ。それだけです。
  2. 🀄
    鳴きも同じ
    ポン・チー・カンで手番が飛んだら、鳴いた人のタイルをタップ。 タイマーがその人に移ります。順番どおりに進むだけなら中央の卓タップでもOK。
  3. 🏁
    局が終わったら
    ロン / ツモ / 流局 をポン、と1回。その場で記録が保存され、 すぐ次の局を始められます（画面中央の「記録 n局」が保存の証拠）。
  4. ↩️
    間違えたら Undo
    手番・時間・直前の記録まで、1手ずつ戻せます（20手まで）。
  5. ⏱️
    時間切れになったら
    持ち時間（10分）を使い切ると自動で3分の延長が1回つきます（タイルに「延長」表示）。 延長も使い切ると点滅して停止。残り30秒で黄色、10秒で赤になります。
  6. 📋
    記録を見る・出す
    右上「ログ」で各局の思考時間を確認、CSV / JSON で出力できます。 設定の「新しい対局を開始」はタイマーだけ初期化 — 記録は消えません。
